How to use

Play mode — jam. Tap pads to fire sounds. Multi-touch works; several pads can play at once.

Edit mode — tap a pad to rename, recolor, record from the mic, or import an audio file (m4a / mp3 / wav / ogg).

Sounds are stored in IndexedDB on this device only — never uploaded to GitHub or any server.

Add to Home Screen (iPhone): Safari → Share → Add to Home Screen.

Mic access needs HTTPS (this site) and your permission the first time you record.
