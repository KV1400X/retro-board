# Retro Board

Installable PWA soundboard for iPhone (and desktop). Dark tool-shop vibe matching [Retro Scan](https://kv1400x.github.io/retro-scan/).

**Live:** https://kv1400x.github.io/retro-board/

## Features

- Large tappable pad grid (3×4)
- **Play** vs **Edit** modes (won’t reassign while jamming)
- Record from mic or import m4a / mp3 / wav / ogg onto a pad
- Rename + recolor pads
- Multi-touch overlapping playback
- Stop-all + volume slider + haptic vibrate when available
- Starter beep/click tones (generated in code — no copyrighted packs)
- Pads + audio stored in **IndexedDB on device only** (never uploaded)
- Add to Home Screen ready (manifest, icons, service worker shell)

## Privacy

No personal data is collected. Custom recordings never leave the phone. This public GitHub Pages site serves only the app shell.

## Local

Open `index.html` over HTTPS (or localhost). Mic recording requires a secure context.
